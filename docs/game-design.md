# 网页小游戏 · 简短游戏设计文档

> 版本：v0.1（待评审）
> 主角素材锁定为项目中「默认状态 / 移动状态 / 动作状态」三组 GIF，全程沿用，不重新绘制。

---

## 1. 游戏类型

2D 横版无尽跑酷 + 挥砍动作（单页网页小游戏，侧视角，风格偏绘本卡通）。

默认玩法基线为「无限奔跑挑战高分」，此基线可在评审后调整。

## 2. 核心玩法

1. 主角在 2D 平面持续向右奔跑，镜头随主角前移，奔跑距离持续增长。
2. 前方不断生成障碍物与敌人。
3. 主角跳跃越过障碍物；挥砍消灭敌人。
4. 碰到障碍物或敌人扣除 1 点生命（共 3 点），生命归零则游戏结束。
5. 得分 = 奔跑距离 + 击杀加分；结算时展示本次成绩并记录历史最高分（本地存储）。

主角三状态与素材的对应关系（状态机）：

| 游戏状态 | 使用素材 | 帧数 / 节奏 | 触发方式 |
|---|---|---|---|
| 待机 idle | 默认状态.gif | 8 帧 · 320ms | 开场、暂停期间站立 |
| 奔跑 run | 移动状态.gif | 12 帧 · 160ms | 移动与跑步循环 |
| 挥砍 attack | 动作状态.gif | 12 帧 · 160ms | 按下攻击键，播完回 run |

## 3. 操作方式

- 键盘（MVP 主操作）：`←/→` 左右移动，`空格 / ↑` 跳跃，`X / J` 挥砍，`P` 暂停。
- 触屏虚拟按键（MVP 暂不实现，列入后续）：左侧左右移动键，右侧跳跃 / 攻击键。

## 4. 胜负条件

- 无尽模式没有终点，不设"胜"。
- 失败条件：生命（3 点）耗尽，游戏结束。
- 挑战目标：刷新历史最高分视为挑战成功。

## 5. 需要的界面

| 界面 | 内容 |
|---|---|
| 开始界面 | 游戏标题、一行动作说明、开始按钮、历史最高分 |
| 游戏界面（HUD） | 得分 / 距离、生命格（3 格）、击杀计数 |
| 暂停遮罩 | 继续 / 重新开始（MVP 可裁剪） |
| 结算界面 | 本次得分、最高分、重新开始按钮 |

## 6. 需要的图像素材

### 已有（锁定使用）

1. 主角三组状态帧：idle 8 帧、run 12 帧、attack 12 帧，均为透明背景，开发前拆帧为 PNG 序列 / 精灵表。

### 待新增（风格须与主角统一）

主角视觉基准（已从素材像素提取的色盘）：
**深灰黑 #1A1A1A · 墨绿 #2E5A32 · 亮绿 #6FA26F · 米白高光 #E0E0C0**

统一风格约定：暗色基底 + 绿色点缀 + 米白高光，描边式绘本卡通。

| 素材 | 说明 | 优先级 |
|---|---|---|
| 背景远景（天空渐变 + 山丘/森林剪影） | 视差滚动，暗色氛围 | 高 |
| 地面（泥土 / 草地条） | 可平铺，与角色落地基准统一 | 高 |
| 障碍物 1~2 种 | 尖刺桩、倒木，深棕/墨绿 + 高光 | 高 |
| 敌人 1 种 | 墨绿系小怪，2~4 帧待机/被击动画 | 中 |
| UI 底板 / 生命格图标 / 标题字 | 米白 + 墨绿，圆角简洁风 | 中 |
| 挥砍残影、尘土、受伤闪白等小特效 | 引擎半透明绘制即可 | 低 |

## 7. MVP 范围

### 包含
- 单页 HTML5 Canvas + 原生 JS 游戏循环，无框架依赖。
- 主角三状态动画加载与切换（idle / run / attack）。
- 自动奔跑 + 跳跃 + 挥砍攻击判定。
- 地面障碍物（跳跃规避）+ 敌人（挥砍击杀）随机生成。
- 生命、计分、结算、重新开始、历史最高分。
- 素材从 GIF 拆帧得到，本地随项目打包。

### 不包含（后续迭代）
- 关卡 / Boss / 道具成长系统、复杂敌人 AI。
- 音效、触屏虚拟按键、多存档、成就系统。
- 复杂粒子与外部美术素材再生成（如需新敌人形象会与主角风格统一生成后确认）。

## 8. 技术备注（本次不实现）

- 用 HTML5 Canvas 单页应用承载全部绘制。
- 三个 GIF 素材在构建阶段拆帧为透明 PNG 精灵表（已在素材分析中完成验证），按状态机切换。
- 分辨率适配：固定内部分辨率逻辑宽高 + 等比缩放适配窗口。
